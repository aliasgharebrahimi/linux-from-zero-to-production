# 📘 Basic Concepts

> **Linux technically refers to the kernel, rather than a complete operating system.**

---

## 🔹 What Is the Kernel?

The kernel is the core component of an operating system. It is responsible for managing hardware resources and facilitating communication between software and hardware.

### 💡 Example:

For instance, when we play music using a music player application, the kernel helps the application interact with the audio hardware, enabling sound to be played through the speakers.

---

## 🔹 Components of an Operating System

An operating system consists of several main components, including:

### 1. Kernel

The kernel is the core of the operating system. It manages hardware resources and handles essential system operations, such as process and memory management.

### 2. Shell

A shell is a program that allows users to interact with the operating system through commands. It interprets user input and executes the appropriate programs.

**Bash** (Bourne Again Shell) is one example of a shell.

### 3. System Utilities

System utilities are programs designed to help users perform various system-related tasks, such as file management, process monitoring, and system administration.

### 4. GUI (Graphical User Interface)

A GUI enables users to interact with the operating system through graphical elements such as windows, icons, menus, and buttons.

### 5. Libraries

Libraries are collections of reusable code and functions that applications can use to perform specific tasks without having to implement everything from scratch.

---

## 🔹 Understanding Linux Distributions

So, what exactly are we installing and using?

A Linux distribution is a complete operating system built around the Linux kernel. It combines the kernel with essential components such as system utilities, libraries, package management tools, and other software.
